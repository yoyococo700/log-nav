# Log de nav

Générateur de log de navigation VFR à partir d'un dossier de vol (.zip, .gpx, .pln, .fpl) : Rm, distances, TSV, altitudes, déclinaison, Fb et fréquences, exporté en PDF.

- `index.html` : formulaire LCH (A4 paysage, pages ajoutées au-delà de 9 points)
- `vfr.html` : formulaire « Log de navigation » (moitié gauche d'un A4 paysage)

Tout tourne dans le navigateur, aucune donnée n'est envoyée.
